# Advisor roster

Jixia currently carries 20 personal advisor lenses. They are review stances,
not claims that a model is a licensed professional or that every lens belongs in
every consultation.

## Management and leadership

- `management-philosophizer` — challenges management choices across several
  operating philosophies.
- `manager-tools-advisor` — applies the Manager Tools results-and-relationships
  discipline.
- `delegation-accountability-coach` — tests delegation, commitments, ownership,
  and follow-through.

## Executive and value creation

- `value-creation-advisor` — uses an operating-partner equity-value lens.
- `capital-allocator` — tests ROIC, tradeoffs, and capital-allocation discipline.
- `ceo-advisor` — integrates the situation around the binding constraint.

This cluster is deliberately returns-first. It counterbalances the
people-centered leadership lenses and should disagree with them when the
tradeoffs are real.

## Productivity and attention

- `attention-coach` — protects focus, flow, and sustainable attention.
- `behavioral-psychologist` — examines motivation, bias, habits, and
  psychological safety.
- `habit-architect` — turns intentions into durable routines and environments.
- `personal-lean-advisor` — applies flow, WIP limits, and waste reduction to
  personal work.
- `personal-systems-integrator` — examines feedback loops and interactions
  across a personal tool system.

## UX and information design

- `ui-design-critic` — critiques compact interfaces and platform-native visual
  quality.
- `ux-researcher` — tests user flows, friction, cognitive load, and interruption.
- `information-architect` — reviews hierarchy, scanability, and dashboard
  information design.

## Operations, service, and work systems

- `ops-excellence-advisor` — applies Lean and Agile operations principles.
- `service-design-reviewer` — examines service journeys, support processes, and
  service-level design.
- `employee-experience-auditor` — reviews end-to-end employee experience.
- `thinking-process-advisor` — examines how the problem is framed and reasoned
  about.

## Domain and value communication

- `dashboard-auditor` — tests dashboard calculations, metric definitions, and
  query correctness.
- `value-translator` — turns technical work into a decision-relevant account of
  business value and cost.

## Model policy

Eight definitions omit a model pin and therefore inherit the host-selected
current session model: `dashboard-auditor`, `management-philosophizer`,
`personal-systems-integrator`, `thinking-process-advisor`, `value-translator`,
`value-creation-advisor`, `capital-allocator`, and `ceo-advisor`.

The other 12 definitions currently request `sonnet` as a cost-and-latency
choice. Whether that model name is available, and what behavior it provides, is
controlled by the host rather than Jixia.
