# Jixia Advisors

Ask “Use Jixia to review this decision” and supply a question, draft, or plan. Ask to see the proposed method and roster first if you want to change them. The advise skill applies the selected lenses, gives the strongest counter-case, and ends with a concrete next action.

This plugin includes the method registry, advisor definitions, historical representatives, and an optional Python planner. It needs no connector, API key, or separate installation. In chat, the lenses are perspectives applied in the conversation; in hosts that support the bundled named agents, they can run separately. The plugin does not send data to an external service or write a counsel log. Your host still processes the conversation under its own settings.

Install in Claude Code:

    /plugin install jixia-advisors --marketplace alexander-vyh/jixia-advisors

For Claude Desktop, ChatGPT Desktop, Codex, and omp, see https://github.com/alexander-vyh/jixia-advisors#desktop-plugins-and-portable-skill
